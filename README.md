# rakathon-env

Terraform prostředí pro Azure hackathon je v adresáři
[`infra/rakathon-env`](infra/rakathon-env/README.md).

Statický účastnický portál s modely, endpointy a přehledem dat je v
[`web`](web/README.md). Nevyžaduje Functions ani jiný backend; v Azure je
připravený pro Static Web Apps Standard s přihlášením pouze do Rakathon tenantu.

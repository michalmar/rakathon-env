Přístup týmu

Vše potřebné najdete
v portálu.

Ukázka: jiný než týmový účet, bez klíče. Identifikátory účtu a tenantu jsou skryté.

Portál pro účastníky zobrazuje týmový API klíč, názvy deploymentů modelů, URL gateway a seznam datových souborů k výzvám. Ke sdíleným modelům přistupujete přes Azure API Management (APIM), AI gateway této akce.

ModelyTýmový klíč použijte pro sdílené modely pro text a kód i generování obrázků.
DataPřes Azure Portal stáhněte soubory k výzvám VZP, dostupné pouze pro čtení.
ProstředíProstředky aplikace vytvářejte v přidělené rg-teamNN.

teamNN označuje váš přidělený tým, například team01. Týmy nemají přímý přístup do portálu Microsoft Foundry ani ke službě Agent Service. Seznamy modelů a souborů jsou snapshoty; v portálu zkontrolujte datum Stav k.

Týmový účet převezmete
na tištěné kartičce.

UPN a TAP vlevo, QR vpravo. Ukázkové údaje neplatí.

Organizátoři plánují předat každému týmu fyzickou kartičku ve formátu vizitky. Vlevo bude UPN (celé přihlašovací jméno týmu) a TAP (Temporary Access Pass); vpravo QR kód odkazující na https://aka.ms/rakathon2026.

  1. Převezměte kartičku svého týmu

    U organizátorů ověřte, že kartička patří vašemu týmu. Ukázkové údaje z tohoto průvodce nepoužívejte.

  2. Naskenujte QR kód a přihlaste se

    QR otevře pouze portál; nepřihlásí vás automaticky. Do přihlášení Microsoftu zadejte celé UPN z kartičky a použijte její TAP. QR neobsahuje UPN ani TAP.

  3. Kartičku chraňte

    Obsahuje přihlašovací údaje. Nefotografujte ji pro veřejné sdílení, nedávejte ji do Gitu ani veřejného chatu. Platnost TAP si ověřte u organizátorů; při ztrátě kartičky nebo nefunkčním TAP je kontaktujte.

TAP není API klíč. Týmový API klíč si zkopírujete až po přihlášení v sekci Váš API klíč. Soukromý soubor teamNN.md, pokud vám jej organizátoři poskytnou, může sloužit jako záložní předání údajů.

Použijte účet
přidělený vašemu týmu.

  • Převezměte tištěnou kartičku svého týmu
  • Přihlaste se celým uživatelským jménem a TAP
  • V portálu zkontrolujte přihlášeného uživatele

  1. Převezměte týmovou kartičku

    Od organizátorů získáte tištěnou kartičku s UPN a TAP. Ověřte si platnost TAP. Pokud dostanete i záložní soubor teamNN.md, uchovávejte ho stejně bezpečně jako kartičku; necommitujte ho ani nesdílejte mimo tým.

  2. Otevřete portál pro účastníky

    Naskenujte QR z kartičky nebo otevřete https://aka.ms/rakathon2026. Pokud jste u Microsoftu již přihlášeni jiným účtem, použijte samostatný profil prohlížeče nebo anonymní okno. Zadejte celé UPN z kartičky, nikoli běžný osobní či pracovní účet.

  3. Dokončete přihlášení k Microsoftu

    Při přihlášení použijte TAP a postupujte podle případných pokynů k nastavení ověřování. V portálu pro účastníky zkontrolujte přihlášeného uživatele.

Upozornění

TAP není API klíč pro modely. Funguje pouze v době platnosti potvrzené organizátory a může být jednorázový. Pokud vypršel, ještě neplatí, byl již použit nebo nelze přihlášení dokončit, požádejte organizátory o pomoc.

Zkopírujte si klíč.
Chraňte ho.

  • Váš API klíč: správný tým, aktivní stav
  • Zkopírujte klíč, Base URL a název deploymentu
  • Klíč posílejte v hlavičce api-key

  1. Zkontrolujte svůj tým

    Otevřete sekci Váš API klíč. Ověřte, že tým odpovídá kartičce a jeho stav je aktivní.

  2. Zkopírujte údaje pro připojení

    Použijte ikonu kopírování u API klíč (hlavička api-key); ikona oka hodnotu zobrazí nebo skryje. Zkopírujte Base URL (OpenAI v1). V sekci Modely rozbalte model a zkopírujte Deployment / model v SDK.

  3. Klíč uložte bezpečně

    Použijte lokální secret, proměnnou prostředí nebo serverové úložiště tajných údajů. Klíč nikdy necommitujte, nevkládejte do veřejného chatu, neukazujte na screenshotech ani nezapisujte do kódu v prohlížeči. Pokud portál klíč nenačte, požádejte organizátory o pomoc nebo použijte záložní API údaje ze soukromého předávacího souboru, pokud jej máte. TAP z kartičky API klíč nenahrazuje.

Gateway má adresu https://apim-rakathon-q7146n.azure-api.net/openai/v1. Stejný klíč funguje pro všechny její deploymenty. Posílejte jej v hlavičce api-key: samotná Authorization: Bearer požadavky neověří. Nepoužívejte přímý endpoint Foundry.

Modely, data a prostředí

Ověřte připojení
jedním krátkým voláním.

  • Vyberte textový deployment ze seznamu
  • Do model zadejte název deploymentu
  • Odpověď asistenta dostanete v JSON

V sekci Modely vyberte textový deployment. Například pro gpt-6-luna je nakonfigurován deployment gpt-6-luna-dz-eu; před použitím ověřte, že je v seznamu. Pokud vyberete jiný textový deployment, změňte v příkladu hodnotu model.

Příklad spusťte v Bashi s nainstalovaným curl. Zadávání klíče je skryté a jeho konkrétní hodnota se neuloží do historie příkazů. Úspěšný požadavek vrátí JSON s odpovědí asistenta.

Bash

export AZURE_CONFIG_DIR="$HOME/.azure-rak"
read -r -s -p "Týmový API klíč: " API_KEY; printf '\n'
export API_KEY
curl --fail-with-body --silent --show-error \
  https://apim-rakathon-q7146n.azure-api.net/openai/v1/chat/completions \
  -H "api-key: $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-6-luna-dz-eu","messages":[{"role":"user","content":"Pozdrav náš tým na hackathonu."}]}'
unset API_KEY

Do prostředí projektu nainstalujte balíček openai. SDK vyžaduje api_key; hodnota "unused" je placeholder, nikoli přihlašovací údaj. Skutečný klíč gateway patří do default_headers.

Python

from getpass import getpass
from openai import OpenAI

client = OpenAI(
    base_url="https://apim-rakathon-q7146n.azure-api.net/openai/v1/",
    api_key="unused",
    default_headers={"api-key": getpass("Týmový API klíč: ")},
)
reply = client.chat.completions.create(
    model="gpt-6-luna-dz-eu",
    messages=[{"role": "user", "content": "Pozdrav náš tým na hackathonu."}],
)
print(reply.choices[0].message.content)

Konfigurace zahrnuje modely OpenAI, xAI, DeepSeek, Moonshot AI / Kimi a Microsoft AI. Generování obrázků používá /images/generations, nikoli /chat/completions; ne každý model podporuje všechna API a parametry. Podle označení EU Data Zone nebo Global vyberte rozsah zpracování povolený pro vaši výzvu. Global neomezuje zpracování pouze na Evropu.

Stáhněte data k výzvě
přes Azure Portal.

  • Data používejte jen pro povolené výzvy VZP

Data používejte pouze tehdy, pokud se týkají vaší výzvy VZP a máte jejich použití povolené. V sekci Datové podklady pouze pro výzvy VZP zvolte Otevřít storage v portálu.

  1. Použijte týmový účet

    Do Azure Portal se přihlaste stejným týmovým účtem. V případě potřeby přepněte adresář na adresář akce uvedený organizátory.

  2. Otevřete datový kontejner

    Ve storage accountu strakathondataq7146n zvolte Containers / Kontejnery a poté data.

  3. Stáhněte soubor

    Použijte ověřování Microsoft Entra ID, vyberte soubor a zvolte Download / Stáhnout.

Portál pro účastníky nestahuje soubory ani negeneruje odkazy ke stažení. Přístup k datům v Azure je oddělený od přihlášení do portálu: vyžaduje role Reader a Storage Blob Data Reader i povolený síťový přístup k úložišti. Pokud přístup nefunguje, požádejte organizátory o kontrolu obojího; nežádejte o klíče úložiště ani neměňte sdílená nastavení.

Vyvíjejte ve vlastní
resource group.

  • Azure Portal: Resource groups, potom rg-teamNN
  • Role Contributor platí v týmové skupině
  • Placené prostředky nejprve konzultujte

V Azure Portal otevřete Resource groups a vyberte přidělenou rg-teamNN. Tým zde má roli Contributor: prostředky aplikace vytvářejte a spravujte v této skupině v mezích Azure policies a dostupných kvót.

Spravujte pouze vlastní skupinu; nejde o samostatnou subscription. Sdílená data jsou pouze pro čtení a skupiny ostatních týmů nejsou součástí vašeho prostředí. Sdílená AI gateway je připravena k použití, takže k volání modelů nepotřebujete vlastní Foundry resource.

Před vytvářením placených prostředků se domluvte s týmem. U organizátorů ověřte povolené služby a náklady na infrastrukturu; níže uvedený rozpočet modelového API není rozpočtem na libovolné prostředky Azure.

Limity a pomoc

Krátká volání
šetří týmový rozpočet.

  • Začněte krátkými prompty a málo souběžnými požadavky
  • Při rate limitu vyčkejte; zastavte opakování ve smyčce
  • Rozpočty potvrzují a přístup obnovují organizátoři

Výchozí konfigurace repozitáře počítá s 1 000 USD na tým pro používání modelů, upozorněním organizátorů při 90 % a pozastavením přístupu po dosažení týmového limitu. Sdílený limit celé akce může zastavit všechny týmy dříve. Výchozí kvóta je 4 miliony tokenů na tým a den, společná pro textové modely.

Jde o výchozí nastavení, nikoli aktuální zůstatek. Skutečný příděl a spotřebu potvrzují organizátoři. Začněte krátkými prompty a malým počtem souběžných požadavků. Při chybách zastavte opakované pokusy ve smyčce; po překročení rate limitu vyčkejte a respektujte Retry-After, pokud je uveden. Pozastavený přístup mohou obnovit pouze organizátoři.

Sdílejte chybu.
Nikdy tajné údaje.

  • Tým, endpoint, deployment, status a čas
  • 401: klíč či pozastavený přístup; 429: limity
  • Skryjte citlivé údaje; neposílejte TAP ani API klíč

  • Přihlášení nefunguje: zkontrolujte celé týmové jméno, platnost a jednorázovost TAP a zda prohlížeč nevybral jiný účet.
  • Účet není týmový: odhlaste se a použijte přidělený účet teamNN.
  • Klíč se nenačítá: zkuste načtení či přihlášení znovu; informujte organizátory nebo použijte záložní API údaje z předávacího souboru, pokud jej máte. TAP není API klíč.
  • HTTP 401: zkontrolujte hlavičku api-key, zkopírovaný klíč, URL gateway a aktivní stav týmu. Pozastavení také vrací 401.
  • Suspended / zablokováno - rozpočet: kontaktujte organizátory. Nový klíč pozastavený přístup neobnoví.
  • HTTP 404 nebo nepodporované parametry: ověřte přesný název deploymentu a API vhodné pro daný model.
  • HTTP 429: rate limit, sdílená kapacita nebo kvóta tokenů; vyčkejte místo opakování ve smyčce.
  • Zamítnutý přístup ke storage: organizátoři zkontrolují účet a adresář, role Reader a Blob Data Reader a povolenou síť.
  • Katalog nefunguje nebo je zastaralý: požádejte organizátory o kontrolu exportu katalogu a nasazení portálu.

Přiložte název týmu, prováděnou akci nebo cestu endpointu, název deploymentu, HTTP status, čas a chybovou zprávu bez citlivých údajů. Nikdy neposílejte TAP ani API klíč.

Můžete začít: správný týmový účet, aktivní klíč gateway a jedno úspěšné volání modelu.

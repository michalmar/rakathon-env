Use the account
assigned to your team.

  • Open the private team handoff
  • Sign in with its full username and TAP
  • Check the username in the portal

  1. Get your private handoff

    The organizers supply teamNN.md: your full username, Temporary Access Pass (TAP), validity window, and backup API connection details. Do not commit it or share it outside your team.

  2. Open the participant portal

    Use a separate browser profile or private window if Microsoft already has another account signed in. Enter the full team username from the handoff, not your usual personal/work account.

  3. Complete Microsoft sign-in

    Use the TAP at Microsoft's sign-in prompt and follow any authentication setup instructions shown. Check the signed-in username in the participant portal.

Warning

The TAP is not the model API key. It works only within the handoff's validity window and may be single-use. If it is expired, not yet valid, already used, or sign-in cannot finish, ask the organizers for help.

The gateway is https://apim-rakathon-q7146n.azure-api.net/openai/v1. The same key works across its deployments. Send it in the api-key header: Authorization: Bearer alone does not authenticate requests. Do not use a direct Foundry endpoint.

Models, data, and workspace

Prove the connection
with one small call.

  • Choose a listed text deployment
  • Use its deployment name as model
  • Expect an assistant reply in JSON

Choose a text deployment in Modely. For example, the configured gpt-6-luna deployment is gpt-6-luna-dz-eu; confirm it is listed before using it. Replace the example's model value if you choose another text deployment.

Run this in Bash with curl installed. The key prompt does not echo the key or put its literal value into shell history. A successful request returns JSON with an assistant reply.

Bash

export AZURE_CONFIG_DIR="$HOME/.azure-rak"
read -r -s -p "Team API key: " API_KEY; printf '\n'
export API_KEY
curl --fail-with-body --silent --show-error \
  https://apim-rakathon-q7146n.azure-api.net/openai/v1/chat/completions \
  -H "api-key: $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-6-luna-dz-eu","messages":[{"role":"user","content":"Say hello to our hackathon team."}]}'
unset API_KEY

Install the openai package in your project's environment. The SDK requires api_key; "unused" is a placeholder, not a credential. The real gateway key goes in default_headers.

Python

from getpass import getpass
from openai import OpenAI

client = OpenAI(
    base_url="https://apim-rakathon-q7146n.azure-api.net/openai/v1/",
    api_key="unused",
    default_headers={"api-key": getpass("Team API key: ")},
)
reply = client.chat.completions.create(
    model="gpt-6-luna-dz-eu",
    messages=[{"role": "user", "content": "Say hello to our hackathon team."}],
)
print(reply.choices[0].message.content)

The configured model families include OpenAI, xAI, DeepSeek, Moonshot AI / Kimi, and Microsoft AI. Image generation uses /images/generations, not /chat/completions; not every model supports every API or parameter. Build inside
your own resource group.

  • Azure Portal: Resource groups, then rg-teamNN
  • Contributor access stays within your team's group
  • Ask before creating paid resources

In Azure Portal, open Resource groups and select your assigned rg-teamNN. Your team has Contributor access there: create and manage application resources within that group, subject to Azure policies and available quotas.

Manage only your own group; this is not an isolated subscription. Shared data is read-only, and other teams' groups are outside your workspace. The shared AI gateway is ready to use, so you do not need your own Foundry resource to call models.

Agree with your teammates before creating paid resources. Ask organizers about allowed services and infrastructure costs; the model API budget below is not an allowance for arbitrary Azure resources.

Limits and help

Small calls
keep your team moving.

  • Start with short prompts and modest concurrency
  • Wait on rate limits; stop retry loops
  • Organizers confirm budgets and restore suspended access

Repository defaults are USD 1,000 per team for model usage, an organizer warning at 90%, and suspension at the team limit. The shared event limit can stop all teams earlier. The default token quota is 4 million tokens per team per day, shared across text models.

These are configured defaults, not a live balance. Organizers confirm your actual allocation and usage. Start with short prompts and modest concurrency. Stop retry loops on failures; retry rate limits with a delay and respect Retry-After when supplied. Only organizers can restore suspended access.

Source

Budget and quota defaults: repository cost-control documentation and Terraform variables, reviewed 12 October 2026. Organizer overrides may differ.

Share the error.
Never the secret.

  • Team, endpoint, deployment, status, and time
  • 401: key or suspended access; 429: limits
  • Redact the error; omit TAP and API key

  • Sign-in fails: check the full team username, TAP validity/single-use status, and whether the browser selected another account.
  • Not a team account: sign out and use the assigned teamNN account.
  • Key does not load: retry or sign in again; use the private handoff as backup and tell organizers.
  • HTTP 401: check the api-key header, copied key, gateway URL, and active team state. Suspension also returns 401.
  • Suspended / zablokováno - rozpočet: contact organizers. A new key does not restore suspended access.
  • HTTP 404 or unsupported parameters: check the exact deployment name and API appropriate to that model.
  • HTTP 429: rate limit, shared capacity, or token quota; wait rather than loop.
  • Storage access denied: organizers check your account/directory, Reader plus Blob Data Reader permissions, and allowed network.
  • Catalog fails or looks outdated: ask organizers to check the catalog export and portal deployment.

Include your team name, action or endpoint path, deployment name, HTTP status, time, and a redacted error message. Never send your TAP or API key.
